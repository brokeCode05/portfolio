Sync settings

Secure Mode — No Service Key Needed

Your Supabase database uses Row Level Security (RLS) with your admin password as the write key. The service role key is NEVER stored in the browser, making this much safer.

-- 1. Enable RLS on portfolio_data table ALTER TABLE portfolio_data ENABLE ROW LEVEL SECURITY; -- 2. Allow public read access (anyone can view your portfolio) CREATE POLICY "Public read portfolio_data" ON portfolio_data FOR SELECT TO anon USING (true); -- 3. SECURITY FIX — writes are function-only. The old "Admin write" policies -- allowed anonymous INSERT/UPDATE and never validated the password header, -- so anyone with the public key could overwrite the site. Drop them: DROP POLICY IF EXISTS "Admin write portfolio_data" ON portfolio_data; DROP POLICY IF EXISTS "Admin update portfolio_data" ON portfolio_data; -- Writes now go through the portfolio-sync edge function, which checks the -- password against PORTFOLIO_SYNC_SECRET server-side. Public SELECT (step 2) -- stays open so visitors can still read the portfolio.

Click the SQL block above to copy, then paste it in your Supabase Dashboard → SQL Editor.

Cloud Sync Password

Set a secret password used to authorize cloud sync writes. This is NOT your login password — it's sent as a custom header that the portfolio-sync edge function checks server-side (matching the PORTFOLIO_SYNC_SECRET secret). Direct REST writes are closed.

Admin Passcode (optional)

Optional second factor on top of the email access code. When set, you'll be asked for this passcode after entering your OTP code. Leave blank to keep the current OTP-only login. Stored in your browser only.

GitHub API Token

Add a GitHub personal access token (public repo scope) to raise API rate limits from 60 to 5,000 requests/hour. Get one from GitHub Settings → Tokens. Stored in your browser only — never shared.

How It Works

  1. Run the SQL above in your Supabase SQL Editor (one-time setup)
  2. Set a Cloud Sync Password above (used for write authorization)
  3. Any Save action auto-publishes to the cloud
  4. Visitors fetch the latest data from Supabase automatically
  5. Changes are instant and worldwide!
