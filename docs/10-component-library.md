# Component Library — Stonerich Granite Construction and Supply

## Global Components

### Navigation
- `Navbar` — Sticky transparent-to-solid with logo, nav links, CTA button
- `MobileMenu` — Slide-in overlay for mobile
- `NavLink` — Individual nav link with active state
- `Dropdown` — Products/Services submenu

### Buttons
- `Button` — Primary (red), Secondary (outline), Ghost variants
- `CTAButton` — Large, high-contrast call-to-action
- `PhoneButton` — Styled for phone number display
- `WhatsAppButton` — Floating or inline

### Typography
- `Heading` — H1-H4 with consistent spacing
- `Text` — Body, body-large, body-small, caption
- `Overline` — Small uppercase label
- `SectionHeader` — Consistent section title + subtitle pattern

### Media
- `Image` — Optimized, lazy-loaded image with aspect ratio
- `Lightbox` — Full-screen image viewer with navigation
- `Gallery` — Grid of images with lightbox trigger
- `ImagePlaceholder` — "Content Required" placeholder

### Cards
- `ProductCard` — Image + title + brief description
- `ServiceCard` — Icon + title + description
- `ProjectCard` — Image + title + category (Content Required)
- `FeatureCard` — Icon + title + description for Why Choose Us

### Layout
- `Container` — Max-width wrapper
- `Section` — Spaced section with optional background
- `Grid` — Responsive grid with column control
- `PageHeader` — Inner page title + breadcrumb

### Feedback
- `LoadingSpinner` — Loading state indicator
- `Skeleton` — Skeleton loader for images
- `Toast` — Success/error notification

## Page-Specific Components

### Home
- `Hero` — Full-viewport hero with overlays and CTAs
- `FeaturedProducts` — Horizontal product category showcase
- `WhyChooseUs` — Trust pillars section
- `ServicesOverview` — Grid of service cards
- `StoneCategories` — Visual grid of all stone types
- `Process` — Numbered steps
- `FAQAccordion` — Expandable Q&A
- `CTABanner` — Full-width call-to-action

### Products
- `ProductGrid` — Filterable grid of product cards
- `ProductDetail` — Full product information layout
- `ProductFilter` — Category filter controls
- `ProductSpecs` — Specification table

### Quote Form
- `QuoteForm` — Multi-field form with validation
- `FormField` — Reusable input/select/textarea
- `FileUpload` — Attachment upload component
- `FormSelect` — Styled select dropdown

### Contact
- `ContactInfo` — Company contact details display
- `ContactForm` — Message form
- `MapPlaceholder` — Embedded Google Maps placeholder

### About
- `CompanyOverview` — About text section
- `ValuesList` — Core values (Content Required)

### FAQ
- `FAQList` — List of accordion items
- `FAQItem` — Single Q&A item

### Services
- `ServiceDetail` — Full service layout
- `ServiceProcess` — Step-by-step process display

### Projects
- `ProjectFilter` — Category filters
- `ProjectCard` — Project card (Content Required)

### Gallery
- `MasonryGrid` — Masonry layout
- `GalleryImage` — Individual gallery item

## Shared Patterns

- Section with gray background
- Section with image background and overlay
- Card hover → subtle elevation
- Button hover → darken + lift
- Link hover → underline or color shift
- Form focus → red accent border
