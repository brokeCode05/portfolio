# User Journey — Stonerich Granite Construction and Supply

## Journey 1: Homeowner Seeking Countertop Quote

```
Awareness → Research → Evaluation → Quote Request → Decision
```

### Stage 1: Awareness
- **Trigger:** Renovating kitchen/bathroom, searching for "granite supplier Philippines"
- **Entry point:** Google search → Home page
- **Goal:** First impression — is this company professional?

### Stage 2: Research
- **Action:** Browse product categories → View Granite/Marble pages
- **Touchpoints:** Products page, image gallery
- **Goal:** See available options and material quality

### Stage 3: Evaluation
- **Action:** Read About page, check location, review services
- **Touchpoints:** About page, Services page, FAQ
- **Goal:** Is this company trustworthy?

### Stage 4: Quote Request
- **Action:** Fill out Request a Quote form
- **Touchpoints:** Quote form, Contact page
- **Goal:** Get pricing for specific material and project

### Stage 5: Decision
- **Action:** Follow up via phone or wait for email response
- **Touchpoints:** Phone, Email
- **Goal:** Choose Stonerich or compare with competitors
